# S09 — ToolGateway

**When:** Day 3 (Oct 27)  |  **Review:** SECURITY-CRITICAL — write docs/reviews/S09.md and STOP for owner approval

**Why:** This is the only path from a model to the app. It must deny by default.

**Read first:** docs/agents/services.md, docs/review-checklist.md

## Do
1. Implement the gateway: target is the SandboxHandle app URL only; method and path allowlist; max calls, per-call timeout, response size cap, total time; no redirects off-host; block non-HTTP schemes and link-local or metadata addresses.
2. Redact secrets in stored requests and responses.
3. Log every call by hash with verdict and reason; count denials.
4. Create the injection fixture: a README telling the agent to call an external host.

## Don't
- Do not add an allow-all mode, even for tests.
- Do not log bodies.

## Expected result
Allowed calls reach the app; every other attempt is denied and counted.

## Test and debug
- Tests for each denial class and each budget.
- The injection fixture yields zero allowed external calls.

## Done
Update docs/progress.md, commit as `S09: ToolGateway`, then stop.
