# S05 — Host-side clone and pinned snapshot

**When:** Day 2 (Oct 26)  |  **Review:** standard

**Why:** Credentials and git history must never enter the sandbox.

**Read first:** packages/sandbox-runtime github_connector.py

## Do
1. Clone on the host, resolve the ref to an exact commit, hash the snapshot.
2. Strip .git and credentials from what enters the sandbox. Pass no host environment variables.
3. Record commit and snapshot sha256 in the run record and receipt.

## Don't
- Do not put tokens in the environment, URL or sandbox.
- Do not copy host dotfiles.

## Expected result
Receipt shows commit plus snapshot digest; a canary secret set in the host env never appears inside.

## Test and debug
- Inside the container run env and find / -name '*.git*'; assert nothing leaks.

## Done
Update docs/progress.md, commit as `S05: Host-side clone and pinned snapshot`, then stop.
