# S08 — Event log and orchestrator

**When:** Day 3 (Oct 27)  |  **Review:** standard

**Why:** Deterministic control flow is what keeps a crew honest.

**Read first:** docs/agents/services.md, docs/contracts.md

## Do
1. Create packages/crew with the Orchestrator: explicit states and transitions, budgets, timeouts, retry policy, teardown always runs.
2. Add the Postgres events table (EventRecord) and an append-only writer; expose a read stream.
3. Validate every stage output against its contract; a violation fails that stage with a reason.
4. Map failures to exit codes through failure_stage.

## Don't
- Do not let an agent choose the next state.
- Do not swallow stage errors.

## Expected result
A run with stub agents walks the full state machine and writes a complete event log.

## Test and debug
- Illegal transitions rejected.
- Contract violation fails the stage.
- Kill mid-run: teardown still runs.

## Done
Update docs/progress.md, commit as `S08: Event log and orchestrator`, then stop.
