# S04 — Docker backend through SandboxExecutor

**When:** Day 2 (Oct 26)  |  **Review:** standard

**Why:** Docker is the cross-platform default and already half-built.

**Read first:** apps/sandbox-executor/src/workflo_executor/executor.py, docker_runner.py, runtime.py

## Do
1. Route the Docker path through ContainerRuntime and produce a RunResult with correct failure_stage for deps, app and tests.
2. Stage 1 deps on a bridge network, record image digest. Stage 2 sealed run on --network none.
3. Stage 2 flags: non-root user, --cap-drop ALL, no-new-privileges, read-only rootfs plus tmpfs, memory, cpus, pids limits, wall-clock timeout.
4. Label every container, network and volume workflo.run_id=<id>.

## Don't
- Do not mount docker.sock into any workload.
- Do not use --privileged or host bind-mounts.
- Do not let stage 2 reach any network.

## Expected result
fixtures/node-bugs builds, boots and runs its tests in the sealed stage.

## Test and debug
- docker inspect the stage-2 container and assert each flag.
- A failing-build fixture must land on failure_stage=deps and exit 3.

Update docs/progress.md, commit as `S04: Docker backend through SandboxExecutor`, then stop.
