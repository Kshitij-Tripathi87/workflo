# S16 — Reporter

**When:** Day 4 (Oct 28)  |  **Review:** standard

**Why:** Readable output that cannot invent facts.

**Read first:** docs/agents/reporter.md

## Do
1. Build the structured ReportBundle from data, including isolation proof and requirement statuses.
2. Optional LLM fills explanation, hypothesis and remediation hint; add the validator and template fallback.
3. Render HTML and JSON by code.

## Don't
- Do not let the model write ids, counts or statuses.
- Do not render a hypothesis as a cause.

## Expected result
A complete report with the LLM off, and the same facts with it on.

## Test and debug
- Reject a draft citing an unknown evidence id.
- Provenance and degraded flags present.

## Done
Update docs/progress.md, commit as `S16: Reporter`, then stop.
