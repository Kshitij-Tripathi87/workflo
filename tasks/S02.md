# S02 — Contracts package

**When:** Day 2 (Oct 26)  |  **Review:** standard

**Why:** Typed handoffs are what make a crew safe. Everything after this step depends on them.

**Read first:** docs/contracts.md, docs/agents/00-overview.md

## Do
1. Create packages/crew-contracts with pydantic v2 models for every contract in docs/contracts.md, extra=forbid, schema_version field.
2. Export JSON Schema for each model to packages/crew-contracts/schemas/.
3. Encode invariants as validators: Confirmed needs >= 2 repro refs and 1 control ref; ReportDraft cited ids subset of finding evidence; ModelCallRecord has no body fields.
4. Add valid and invalid fixture JSON for each contract.

## Don't
- Do not add optional escape-hatch fields like 'extra' or 'metadata: dict'.
- Do not import anything from crew or sandbox packages here.

## Expected result
Every contract round-trips, every invalid fixture is rejected, schemas are generated.

## Test and debug
- Unit tests per contract and per invariant.
- Test that an unknown field is rejected for every model.

## Done
Update docs/progress.md, commit as `S02: Contracts package`, then stop.
